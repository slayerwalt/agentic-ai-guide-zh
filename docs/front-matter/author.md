# 关于作者 {#about-the-author}

<aside class="page-attribution" aria-label="本页署名">
作者：Haggai Roitman
</aside>

<p><strong>Haggai Roitman</strong> 在 AI 研究与大规模生产系统的交叉点上耕耘了二十余年。他的工作贯通理论与实践——从发表基础性研究，到交付服务数百万用户的系统。</p>

<p>他的研究兴趣涵盖信息检索、推荐系统、自然语言处理、大语言模型、面向 LLM 的强化学习以及智能体 AI。他已发表逾 100 篇同行评审论文，并拥有约 100 项专利。他在 Technion——以色列理工学院取得本科（<em>Cum Laude</em> 优等）与博士学位。</p>

<p>当他不在思考梯度流与 KV 缓存时，可以在打碟机前找到他——在那里他混音 progressive trance 与 deep house。</p>
